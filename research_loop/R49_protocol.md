# R49: disjoint roles for the allowed support labels

Frozen after R48. R48 shows that some amplitude information transfers between disjoint evaluation panels, especially the dominant full pool. It does not establish identification from31allowed labels. Test one role-allocation mechanism, not another coefficient grid.

For n>=7 (both halves contain at least3examples), use four fixed random balanced partitions of the current support rows. For each partition fit the unchanged ridge direction on halfA and fit a clipped-ray scale c in[0,4] on halfB, then reverse. Each head's Beta(1,1) base and ridge slope use ONLY its fitting half. The calibration labels affect ONLY its scale. Average eight query predictions. n=0,1,3 uses unchanged full-support R25. Randomness fixed4901, depends only on support length/order, never evaluation labels, benchmark identity or previous calls. This sacrifices direction sample size to obtain a genuine held-out calibration panel; the experiment tests that tradeoff.

Controls: same eight split heads with c=1; same heads with calibration directions deterministically permuted relative to calibration outcomes; original full-support R25; smoothed2. The scale solver is the already numerically tested one-dimensional squared-loss solver, but here receives only allowed support labels. No R33/R48 coefficient or query outcome is reused. Split controls share any additional prior shrinkage caused by fitting on half-samples, so gains over the split control alone are insufficient.

Use original three source pools seed73/max25pairs/64queryitems and all response rows. Freeze design and source hashes, replay original R25 source ALC. No search over split fraction, repetitions, scale bound or calibration penalty. Enter outer evaluation only if the candidate improves pair-equal AND benchmark-equal ALC versus original R25 in all three source pools and improves pair-equal versus both split/no-scale and calibration-permuted controls in all pools. Otherwise stop this role-allocation design. Pilot scores are not OOD performance.

Tests before scores: zero/one/three-label exact fallback, label complement symmetry, finite deterministic probabilities, independent query inputs cannot alter support-fitted scales; scored query labels are not an argument. There is no cross-call fitted state. These are within-call support permutations, not changes to acquisition order/strategy.

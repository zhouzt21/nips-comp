# R42: support-conditioned template removal, source-only pilot

Frozen after R41. Raw benger examples contain different legal case bodies but long identical instructions. Original processing puts common early user instructions and late system text into the126token window. Exact collisions are not the main explanation for alignment_faking, so do not claim this repair solves the whole task. New mechanism question: can current support context identify invariant text, allowing the same frozen encoder/window to encode variable problem content? Unlike R18, neither token budget nor encoder changes; unlike R2, the representation is conditioned on CURRENT allowed support inputs.

At each budget n>=3 use the original canonical token sequences of the current n support inputs only. Find their longest common prefix and nonoverlapping suffix. If all sequences identical or prefix+suffix<32tokens, keep the original window. Otherwise remove the common affixes except8tokens of context at each variable-region boundary. Apply this template to an individual query only if BOTH affixes match exactly; otherwise use its original sequence. Then use the original first96+last30 truncation. Query inputs never define or alter the template. n0/1 remain smoothed2. These constants describe one fixed information-selection rule; no grid.

Freeze MiniLM revision, original pooling, R25 semantic ridge4/4/1, metadata ridge16. Contrast old versus template-conditioned semantic features. Matched lexical control hashes the corresponding retained windows using the existing encoder and ridge1 plus unchanged metadata16; it diagnoses whether any improvement is due to exposing content, rather than extra pretrained semantics. Keep old smoothed2. Same current support labels/response weights; no peer evidence, benchmark IDs or opaque metadata identity features.

Pilot scope: original source-only seed73/max25pairs per benchmark, original50/50split,31support and64queryitems/allresponses. No parameter fitting. Save three source-fold summaries BEFORE any outer evaluation. Admit to a later frozen outer run only if semantic ALC improves against old R25 in ALL THREE source folds and benchmark-equal source mean also improves. These are source-development observations, not OOD evidence; a failed admission stops this affix rule without boundary/token/threshold grids.

Before encoding, log unique changed windows and changed-query fraction per benchmark. Use original offline tokenizer/model, new D-drive token-window cache; no downloads. Reuse original cached semantic vectors when window is unchanged. Token hashes key representation only, not labels. Tests verify affix construction, mismatched query fallback, no variable-support fallback, target-batch independence and budget-prefix isolation. Check frozen-model forward equivalence on unchanged windows to1e-5. Runtime limit is not a score-selection knob; long jobs resume from completed benchmark files with matching source hashes. No promotion or ZIP based on this pilot alone.

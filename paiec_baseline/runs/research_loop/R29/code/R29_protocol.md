# R29: transfer task covariance without transferring label direction

Frozen before scoring, 2026-10-22. Current observations: R22 supervised semantic prior remains unreliable; R28 symmetry alone does not make source prevalence useful; R7 current-label semantic slopes give small gains. R5 learned a diagonal HASH metric and failed, which does not test off-diagonal semantic task covariance. New hypothesis: source tasks can identify useful semantic directions even when their label slopes change sign across tasks.

Operator sequence: separate transferable geometry from task-specific direction -> sign-invariant source statistic -> nested benchmark selection -> correspondence-destroying control. The Bayesian last-layer interpretation is conceptual inspiration from the already inspected ALPaCA paper (arXiv1807.08912, Gaussian model); this is not its reproduction or a Bernoulli posterior guarantee.

For each source episode, fit a centered semantic ridge slope beta from its 31 acquired labels only, ridge=4. Average beta beta^T within benchmark, then equally across benchmarks. Retain the largest 16 eigen-directions with eigenvalues rescaled to trace384. This covariance is invariant to reversing all labels of any source pair. Test covariance (1-rho)I + rho C, rho in [0,.25,.75]. Zero-label mean remains0.5; local support estimates slope sign. Freeze R7 outer-fold-specific ridge and all other prediction details. Do not add metadata simultaneously.

Within each outer training set, form two deterministic benchmark halves using seed2901. Fit covariance on one half, evaluate rho on the other, swap, then choose rho by aggregate pair-equal ALC. Refit covariance on all outer training benchmarks only AFTER selecting rho. Same nested process for a control that permutes source support labels independently within each pair before covariance fitting, preserving features and prevalence. Both must be finished for all outer folds before any outer scoring.

Outer seed0 uses exactly the historical 737 pairs, 36 benchmarks, evaluation responses and trajectories. Report learned metric, shuffled-source metric, frozen R7 semantic, R25 (separate metadata), fixed/training-selected smoothing. Check exact rho0 fallback and label-complement invariance. Save covariances, spectra, source and inner splits, selection losses, fingerprints and timings.

Proceed to three-seed verification only if learned metric improves all outer folds versus R7 and improves mean versus independently selected shuffled-source control, with benchmark-cluster CI upper<0 against R7. Otherwise stop this source-covariance estimator without expanding ranks or rho grid on outer results. Research gate remains0.005 against strong simple baselines, plus stability/mechanism/generalization/submission conditions. These are repeatedly reused public benchmarks, not blind evidence.
